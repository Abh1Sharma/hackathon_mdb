02 · The solution

A checkpoint between the agent and the money.

  1. Identify the agent and the person it acts for.
  2. Check the written rules. The default is no.
  3. Search every decision a human has made before.
  4. Allow with a single-use warrant, hold for a human, or refuse.
  5. Record it, in the same transaction.

Rules are the statute. Human decisions are the case law. Search can tighten a decision. Only a person can loosen one.

07 · What MongoDB Atlas does

One cluster. No vector database, no embedding service, no queue.

  • Automated Embedding: a ruling is searchable about a second after it is saved.
  • $rankFusion and $rerank: meaning, keywords and a second check in one query.
  • Transactions: decision, warrant and ledger entry commit together.
  • Policies as documents: Sam changes one number by voice.
  • Change streams: the kill switch and the live screen.
  • Validators and indexes: the database refuses a bad write.
Difficulty 30%Each one is load-bearing. Take one away and part of the demo stops.
